# 💡 Light On / Off

A small interactive page that asks: *"Can you turn the light on?"* Flip the toggle switch to turn the light bulb on and off.

## ✨ Features

- Animated **ON / OFF toggle switch**
- Swaps between light-bulb-on and light-bulb-off images
- Glow effect on the bulb when the light is on

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

```
4 light on-off/

```
